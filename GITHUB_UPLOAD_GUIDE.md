# Publish this project on GitHub

## 1. Create the repository

1. Sign in at https://github.com.
2. Select **+** in the top-right corner, then **New repository**.
3. Repository name: `pricing-generator`.
4. Description: `Configuration-driven Python desktop application that converts structured Excel pricing into validated, upload-ready CSV files.`
5. Choose **Public**.
6. Leave **Add a README**, **.gitignore**, and **license** unchecked because they are already included here.
7. Select **Create repository**.

## 2. Upload the files using the website

1. Extract the ZIP on your computer.
2. Open the new empty GitHub repository.
3. Select **uploading an existing file**.
4. Open the extracted `pricing-generator-portfolio` folder.
5. Drag all of its contents into the GitHub upload area. Upload the contents, not the enclosing folder.
6. Wait until every file is listed.
7. Commit message: `Add portfolio-ready Pricing Generator project`.
8. Select **Commit changes**.

GitHub's browser uploader can struggle with folders containing many files. If it does, use GitHub Desktop:

1. Install GitHub Desktop from https://desktop.github.com.
2. In GitHub Desktop, choose **File > Add local repository** and select the extracted folder.
3. If prompted, choose **create a repository here**.
4. Commit with `Add portfolio-ready Pricing Generator project`.
5. Select **Publish repository**, ensure **Keep this code private** is unchecked, and publish.

## 3. Finish the repository page

1. On the repository page, select the gear icon next to **About**.
2. Add description: `Python desktop app for validated pricing extraction and upload-ready CSV generation.`
3. Add topics: `python`, `pandas`, `excel-automation`, `customtkinter`, `data-validation`, `desktop-application`, `portfolio-project`.
4. Enable **Releases** only if you later add a safe demo executable.
5. Do not upload the real workbook, real output files, logs, or production executable.

## 4. Pin it to your profile

1. Open your GitHub profile.
2. Select **Customize your pins**.
3. Select `pricing-generator` and save.
